## Background
I (and many other people) find it incredibly annoying that input components/widgets like sliders and dropdowns change their values when a user hovers over them and scrolls.
None of the times I've scrolled to change a dropdown's value has been intentional.
It's unbelievably frustrating to always have to remember to be careful when scrolling in one of the default KDE apps (System Settings, KWrite, Discover, Dolphin, and much more).
I'd call that behaviour quite unique to KDE, since I've almost never seen that feature in any other software,
which is why I find it disgraceful that such behaviour cannot be configured or turned off.
People have opened discussions, issues and pull requests about this for nearly a decade (maybe even more), but they've all been closed,
ignored or forgotten about for one reason or another. Thus I've decided to stop hoping for an upstream fix, take it into my own (or rather, the clanker's) hands, and fix it for myself once and for all.
